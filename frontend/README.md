# Frontend

React + TypeScript + Vite scaffold for the analytics UI layer.

## Structure

- `src/components` - reusable presentational components
- `src/pages` - route-level views
- `src/hooks` - reusable behavior hooks
- `src/api` - backend API client modules
- `src/charts` - visualization components
- `src/tables` - table components and helpers
- `src/types` - shared frontend types
- `src/utils` - shared utilities (including logging)

## Local commands

```bash
npm install
npm run dev
npm run lint
npm run format:check
npm run test
```
